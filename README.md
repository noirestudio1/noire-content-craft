# SANS RETOUR Studio Launch

Create a complete premium website for a Romanian short-form content production agency called SANS RETOUR.

BRAND:
Name: SANS RETOUR
Descriptor: CONTENT STUDIO
Future domain: TBD

SANS RETOUR is NOT a traditional digital marketing agency.
We specialize in creating organic short-form video content for businesses.

Our service:
- We research the client's business
- We develop content ideas
- We create hooks and scripts
- We tell the client exactly what to say on camera
- We come to their location and shoot the content
- We professionally edit the videos
- We create a posting calendar
- We can either deliver everything ready to post or manage the posting for them

Target clients:
- aesthetic & beauty clinics
- dental clinics
- restaurants
- automotive detailing businesses
- gyms and fitness studios
- real estate agencies
- premium local businesses

Primary cities initially: Bucharest and Brasov, Romania.

LANGUAGE:
The entire customer-facing website should be written in Romanian.
The brand name and occasional short creative phrases such as "CONTENT STUDIO" may remain in English.

BRAND PERSONALITY:
Premium
Cinematic
Confident
Modern
Minimal
Editorial
Sophisticated

Do NOT make the website look like a generic SaaS startup or generic marketing agency.

VISUAL IDENTITY:

Main background:
near-black / charcoal (#0B0B0B approximately)

Primary text:
warm ivory / off-white

Accent:
champagne gold

Gold should be elegant and restrained.
DO NOT use bright yellow gold.
DO NOT overuse gold.

Use lots of negative space.

Typography should feel like a combination of:
luxury fashion editorial + modern creative studio.

Use large typography and dramatic spacing.

SANS RETOUR logo should simply be:
SANS RETOUR
with CONTENT STUDIO underneath in small spaced-out uppercase letters.

SITE EXPERIENCE:

The website must feel cinematic and expensive.

Use subtle:
- fade animations
- reveal-on-scroll animations
- smooth transitions
- elegant hover effects
- text reveals
- subtle parallax where appropriate

Do NOT overanimate.
Performance and mobile usability are more important than effects.

Build the site MOBILE-FIRST but make the desktop version visually impressive.

IMPORTANT FUNCTIONAL REQUIREMENTS:

Make the site fully responsive.

Prioritize mobile experience.

Use semantic HTML and SEO-friendly structure.

Create appropriate page title:
SANS RETOUR Content Studio | Content pentru Business

Meta description:
SANS RETOUR creează content video pentru businessuri din București și Brașov: strategie, scenarii, filmare, editare și planificare pentru TikTok, Instagram Reels și YouTube Shorts.

Optimize loading performance.

Lazy-load videos and heavy visual assets.

Make navigation work correctly.

Make all CTA buttons scroll or link to the correct sections.

Create reusable components.

Avoid unnecessary dependencies.

Keep code clean and easy to export/deploy later.

Do not require any paid API or paid third-party service for the website to function.

Do not implement paid services.

Forms should be architected so they can later be connected to a free form endpoint or backend.

Do not create fake reviews, fake clients, fake testimonials, fake case-study metrics or fake social proof.

Do not invent phone numbers, emails or social accounts.

Use placeholders clearly marked for later replacement.

Make the website feel like a €10,000+ European luxury creative studio website, while remaining extremely clean and easy for a Romanian local business owner to understand.

The primary goal is lead generation.

The visitor should understand within 5 seconds:

1. SANS RETOUR creates social video content for businesses.
2. The client does not need to come up with ideas or scripts.
3. SANS RETOUR handles the production process.
4. There is a clear way to request an offer or receive 3 free content ideas.

Before completing, check the entire site for:
- mobile responsiveness
- broken navigation
- text contrast
- excessive animations
- placeholder clarity
- CTA consistency
- Romanian diacritics
- loading performance
